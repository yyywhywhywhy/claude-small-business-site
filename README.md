# Claude for Small Business — site

Static site. No build step, no dependencies.

  index.html                  landing page
  guides-seo-autopilot.html   the SEO guide

## Deploy

Either drag this folder onto https://app.netlify.com/drop,
or push it to a GitHub repo and import that repo at https://vercel.com/new.
No framework — choose "Other" / no build command if asked.

## Before it works properly

1. Email form (index.html, 2 places): replace action="#" with your
   email tool's form endpoint (MailerLite / Kit / Beehiiv).
2. Social links in the footer.
3. Search for "REPLACE" to find everything outstanding.
